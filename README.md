# NIC Robotics — Website

Offizielle Website von NIC Robotics: https://www.nic-robotics.de

Statische Website (HTML/CSS/JS) in Deutsch, Englisch und Chinesisch.
Die Seiten werden mit `node build/build.js && node build/build-pages.js` aus den Quellen erzeugt
(Node.js ≥ 18, keine Abhängigkeiten). Die erzeugten `.html`-Dateien werden mit eingecheckt.

Veröffentlichung: automatisch über Cloudflare Pages bei jedem Push auf `main`.
Hinweise für Änderungen: siehe `AGENTS.md`.
